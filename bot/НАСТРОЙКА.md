# Telegram-бот SMC Signals: настройка

Бот работает на серверах GitHub (GitHub Actions). Свой сервер и открытая вкладка не нужны. Примерно раз в 10 минут он проверяет рынок по тем же правилам, что и приложение, и присылает в Telegram:

- **новый сигнал**: сторона, монета, пресет, профиль, score, лимитный вход, SL с риском в процентах, TP1–TP3, срок ожидания входа;
- **вход исполнен**;
- **TP1**: закрыть 40%, стоп в безубыток (с ценой);
- **TP2**: закрыть ещё 30%, стоп на TP1;
- **закрытие сделки** с итогом в R;
- **«отмените лимитный ордер»**, если вход не случился или сигнал отменён;
- **итоги недели** по понедельникам: бумажная проверка, итог за неделю и с начала.

Настройки бота — те же, что у кнопки «Качественный режим» в приложении (`CONFIG.qualityPreset` в `js/config.js`).

Бот только подсказывает: он не торгует и не знает ваших биржевых ключей. Это не финансовая рекомендация.

## Подключение (один раз, около 10 минут)

Все шаги можно сделать с телефона. GitHub удобнее открывать в браузере, включив «Версия для ПК».

1. **Создайте бота в Telegram.**
   - Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
   - Придумайте имя, затем username, который заканчивается на `bot`.
   - BotFather пришлёт **токен** вида `123456789:AA…`. Это пароль бота: никому его не пересылайте, в том числе в чат с Claude.
2. **Сохраните токен в GitHub.**
   - Откройте репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
   - Name: `TELEGRAM_BOT_TOKEN`, Secret: токен из шага 1. Нажмите **Add secret**.
3. **Напишите боту.** Откройте своего бота в Telegram (ссылка `t.me/<username>` есть в сообщении BotFather) и нажмите **Start**.
4. **Запустите проверку вручную.**
   - В репозитории откройте вкладку **Actions**. Если GitHub спросит, разрешите запуск workflow.
   - Выберите **Telegram-сигналы** → **Run workflow** → **Run workflow**.
   - Через 1–2 минуты бот пришлёт в Telegram ваш **chat id** — это число.
5. **Сохраните chat id.** Там же, в **Settings → Secrets and variables → Actions → New repository secret**: Name `TELEGRAM_CHAT_ID`, Secret — число из шага 4.
6. **Запустите workflow ещё раз** (как в шаге 4) или подождите до 10 минут. Бот пришлёт приветствие. С этого момента он пишет о новых сигналах.

О сигналах, которые уже были открыты до подключения, бот не пишет — их видно в приложении.

## Что нужно знать

- **Задержки.** GitHub запускает расписание с задержкой, обычно 5–15 минут, иногда больше. Если сигнал найден с опозданием, в сообщении будет пометка. При долгом ожидании входа (24 ч на основном пресете и 4 дня на свинге) большинство сигналов успевают прийти до входа.
- **Источник данных.** Серверы GitHub находятся в США, а Binance Futures и Bybit оттуда, скорее всего, недоступны. Тогда бот берёт свечи спота Binance (официальное зеркало `data-api.binance.vision`) и пишет об этом в сообщениях. Уровни на споте могут немного отличаться от приложения, которое смотрит фьючерсы.
- **Состояние и журнал** хранятся в ветке `bot-state` репозитория: `state.json` — сигналы, `status.json` — последний запуск, источник, ошибки. Ветка публичная, но токена и chat id там нет.
- **Остановить бота:** Actions → Telegram-сигналы → «…» → **Disable workflow**. Включить снова — **Enable workflow**.
- **Если GitHub сам отключил расписание:** у публичных репозиториев оно отключается после 60 дней без активности. Включите workflow заново кнопкой **Enable workflow**.
- **Если токен утёк:** в @BotFather отправьте `/revoke`, выберите бота, получите новый токен и замените секрет `TELEGRAM_BOT_TOKEN`.

## Если сообщения не приходят

- **Посмотрите последний запуск.** Actions → Telegram-сигналы → последний запуск → шаг «Проверка рынка и уведомления». В логе видны источник, число монет, найденные сигналы и ошибки Telegram. Токена и chat id в логе нет.
- **Проверьте имена секретов:** `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, буквы в точности такие.
- **Ошибка `chat not found` или `bot was blocked`:** напишите боту `/start` и проверьте число в `TELEGRAM_CHAT_ID`.
- **Шаг «Сохранить состояние» упал с ошибкой 403:** Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

## Запуск на своём компьютере (необязательно)

Нужен Node.js 20 или новее. Из папки проекта:

```
node bot/run.js --state state --dry
```

`--dry` — без отправки в Telegram.

Другие ключи:
- `--source binanceSpot` — источник данных;
- `--lookback 192` — окно детектора в свечах младшего ТФ;
- `--block fapi.binance.com,api.binance.com,api.bybit.com` — имитация блокировки, как у серверов GitHub;
- `--demo-messages` — показать все виды сообщений.

Если интернет идёт через прокси из переменных `HTTP_PROXY` и `HTTPS_PROXY`, добавьте переменную окружения `NODE_USE_ENV_PROXY=1`.
